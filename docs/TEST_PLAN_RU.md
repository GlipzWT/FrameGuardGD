# План проверки в Geometry Dash

**Статус всех игровых пунктов: НЕ ПРОВЕРЕНО.** Для изменения статуса нужен запуск
собранного Windows-мода в целевой версии игры. Сначала сделайте резервные копии.

## 1. Сборка и загрузка

- [ ] Независимые тесты зелёные; Windows job завершился успешно.
- [ ] Пакет загрузился без unresolved symbol / missing hook / version mismatch.
- [ ] При отключённом моде игра работает как без него.
- [ ] При enabled=false ни одно нажатие/отпускание не задерживается.

## 2. Интерфейс

- [ ] Кнопка FG доступна в главном меню и ничего не перекрывает.
- [ ] F7 открывает ровно одну панель, F8 меняет enabled один раз за нажатие.
- [ ] Удерживание F7/F8 не создаёт повторов.
- [ ] Оба бинда переназначаются в настройках Geode.
- [ ] Слайдер и +/- дают только целые числа 0–10.
- [ ] Значения настроек сохраняются между запусками.
- [ ] Пропорции 16:9, 4:3 и масштаб UI: текст не обрезан, кнопки нажимаются.
- [ ] Меню во время игры ставит паузу, закрытие оставляет паузу.
- [ ] Rollback помечен как LOCAL / EXPERIMENTAL и выключен по умолчанию.

## 3. Ввод без rollback

Создать короткий статичный уровень с Wave-порталом и обычными блоками,
войти в Practice и дождаться Warming up → готовности после портала.

- [ ] Окно 0: поведение совпадает с чистой игрой.
- [ ] Окна 1, 5, 10: принятая задержка никогда не больше окна.
- [ ] Если немедленный ввод по модели безопасен, offset=0.
- [ ] Раннее нажатие на тестовом коридоре переносится вперёд.
- [ ] Раннее отпускание корректируется отдельно.
- [ ] Поздний ввод без rollback НЕ переносится в прошлое.
- [ ] Неудачный прогноз не отключает обычную смерть.
- [ ] Press → release до наступления delayed press не оставляет кнопку зажатой.
- [ ] Очень частые чередования не меняют порядок фронтов.
- [ ] Pause/reset/disable/settings во время ожидания не оставляют pending edge.
- [ ] Отключение presses не отключает releases и наоборот.

Проверьте, когда в реальности вызываются handleButton, processCommands,
PlayerObject::update и checkCollisions. Используйте временный лог с номером
физического тика; не судите о точности по кадрам видеозаписи.

## 4. Локальный rollback

Включать только на отдельном одноразовом статичном тренировочном уровне.

- [ ] Позднее нажатие на 1…N шагов восстанавливает путь без касания препятствия.
- [ ] Позднее отпускание проверено отдельно.
- [ ] Нельзя перейти через предыдущее событие ввода.
- [ ] Нельзя выбрать snapshot после первого смертельного контакта.
- [ ] При отсутствии ввода после столкновения смерть наступает не позже
      заданного числа следующих физических обновлений.
- [ ] Повторные столкновения не продлевают grace.
- [ ] Коллизия с неподдерживаемым объектом не подавляется.
- [ ] Выключение rollback при активном grace немедленно фиксирует смерть.
- [ ] Pause/F7/F8 при активном grace не превращают его в noclip.
- [ ] После спасения checkpoint/стрик/позиция/направление кнопки согласованы.
- [ ] Несколько смертей/рестартов подряд не оставляют старые snapshots.
- [ ] Нет утечек/зависаний при 15 минутах повторных попыток.

## 5. Отказы и границы применимости

- [ ] Обычный, не Practice, режим: помощь не работает.
- [ ] Dual, platformer, reverse, sideways, slopes: помощь не работает.
- [ ] Уровень с move/spawn/follow/timewarp/другими триггерами: audit отклоняет.
- [ ] Рядом с порталом прогноз не пересекает барьер портала.
- [ ] Переход normal/mini, gravity, speed, другой timestep сбрасывает историю.
- [ ] Уменьшение окна не позволяет использовать старый большой диапазон.
- [ ] Смена уровня не сохраняет объекты/состояние предыдущего.
- [ ] Выход в главное меню и повторный вход не приводит к use-after-free.

## Критерий готовности

Не обозначать альфу как готовый надёжный мод до успешной Windows-сборки,
проверки всех этих пунктов и публикации известных ограничений. Для полного
rollback нужен отдельный движок снимков мира и детерминированный replay,
а не простое снятие ограничений этой версии.
